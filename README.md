Reflectie van Sam Leegwater op het javascript PO
Ik heb van dit project genoten en veel geleerd over programmeren in Javascript. In het begin had ik het idee dat Javascript een soort moeilijkere versie van Python was, omdat de talen op sommige punten wel op elkaar lijken. Toch merkte ik al snel dat ze in werkelijkheid behoorlijk verschillend zijn, vooral in de manier van schrijven en hoe je met elementen zoals functies, variabelen en interactie met de webpagina omgaat.
Tijdens dit project hebben we minimaal gebruikgemaakt van AI. Als we AI hebben gebruikt, hebben we dit duidelijk vermeld in het Pdf-bestand. We hebben geprobeerd zoveel mogelijk zelf de code te begrijpen en te schrijven, zodat we echt konden leren van het proces en niet alleen het eindresultaat.
Ik heb in dit project veel opgestoken over hoe javascript werkt binnen een webpagina. Vooral het werken met knoppen, invoervelden en voorwaarden (if/Else) vond ik interessant. Hierdoor kreeg ik een beter beeld van hoe interactieve websites eigenlijk functioneren.
Hoewel ik in het begin dacht dat ik niet veel nieuws zou leren, bleek dat toch anders te zijn. javascript lijkt op Python in de basis, maar de verschillen zitten juist in de details, zoals syntaxis, het gebruik van DOM-elementen en hoe de code wordt uitgevoerd in de browser. Dat maakte het soms uitdagend, maar ook leerzaam.
Al met al ben ik tevreden over wat ik heb geleerd tijdens dit project. Ik voel me nu zekerder in het gebruik van javascript en begrijp beter hoe programmeren voor webpagina’s werkt. Ik denk dat deze kennis goed van pas zal komen bij toekomstige projecten.
